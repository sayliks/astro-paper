# sayliks corner

一个个人博客，记录学习笔记、项目过程、阅读、音乐以及日常的想法。

基于 [AstroPaper](https://github.com/satnaing/astro-paper) 构建，但本仓库是个人发布空间，不是可复用的主题模板。

##

建这个站的初衷很简单：想要一个属于自己的角落。

不追求完美，不追求更新频率，不追求 SEO，不追求粉丝数。想写的时候就写，不想写的时候就放着。文章可能很短，也可能很长，可能很认真，也可能很随意。

技术栈选了 Astro，因为够快、够简单。Tailwind CSS 让样式写起来很爽，Pagefind 提供离线搜索，Giscus 接 GitHub Discussions 做评论。一切都很轻量，没有数据库，没有后端，纯静态，Vercel 一推就上线。

如果你偶然路过这里，欢迎随便看看。如果有什么想说的，可以在文章下面留言。
