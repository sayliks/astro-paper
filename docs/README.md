# Documentation Index

Use this folder as the handoff point before starting the next implementation
pass. The documents are intentionally split by purpose so old planning notes do
not compete with the active queue.

## Active Handoff

- `optimization-roadmap-2026-06-09.md` is the canonical next-step backlog. Start
  there when choosing the next optimization task.
- `optimization-opportunities.md` is the supporting technical analysis. Use it
  for context after selecting an item from the roadmap.

## Feature Notes

- `moments-development.md` records the current static Moments implementation,
  content model, routing, validation expectations, and deliberately deferred
  functionality.
- `photo-wall-development.md` records the implemented photo wall behavior,
  asset policy, CMS data model, and validation checklist.

## Cleanup Rule

When a planned feature is implemented, update its document from future-tense
planning language to current implementation notes. Keep only still-actionable
future work in a short deferred section.
